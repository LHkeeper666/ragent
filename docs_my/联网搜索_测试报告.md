Redis（Remote Dictionary Server）是一个开源的**内存数据结构存储系统**，常被用作数据库、缓存和消息中间件。它以高性能著称，支持每秒数十万次的读写操作，主要因为数据存储在内存中，并采用单线程事件驱动模型来高效处理并发请求 [来源：菜鸟教程](https://www.runoob.com/redis/redis-intro.html)。

Redis 支持丰富的数据类型，包括：
- **字符串（String）**
- **哈希（Hash）**
- **列表（List）**
- **集合（Set）**
- **有序集合（Sorted Set / ZSet）**

这些数据结构使得 Redis 不仅能做简单缓存，还能用于实现排行榜、计数器、消息队列、会话存储、实时分析等复杂场景 [来源：Redis 中文网](https://redis.com.cn/redis-intro.html)。

此外，Redis 还提供以下关键特性：
- **持久化机制**：支持 RDB（快照）和 AOF（追加日志）两种方式，确保数据在重启后不丢失；
- **发布/订阅（Pub/Sub）**：可用于构建轻量级消息系统；
- **主从复制与高可用**：通过主从架构实现读写分离和故障备份，配合 Redis Sentinel 可实现自动故障转移；
- **事务支持与 Lua 脚本**：允许将多个命令打包执行或运行服务器端脚本，保证原子性操作 [来源：IBM](https://www.ibm.com/cn-zh/think/topics/redis)。

由于其高性能和灵活性，Redis 被广泛应用于 Web 应用的缓存层、热点数据存储、分布式锁等场景。

YOLO（You Only Look Once）是一种**实时目标检测算法**，由 Joseph Redmon 等人在 2015 年首次提出。它的核心思想是将目标检测任务视为一个**单次回归问题**——只需对图像“看一次”，就能同时预测出图像中多个物体的类别和位置边界框，因此得名“You Only Look Once”[来源：知乎专栏](https://zhuanlan.zhihu.com/p/94986199)。

与传统两阶段检测器（如 R-CNN 系列）不同，YOLO 将整张图像划分为一个网格（例如 7×7），每个网格单元负责预测若干个边界框及其对应的类别概率。这种端到端的设计使其在保持较高检测精度的同时，具备极快的推理速度，适用于实时应用场景，如自动驾驶、视频监控等 [来源：CSDN博客](https://blog.csdn.net/fengbingchun/article/details/137995238)。

YOLO 后续发展出多个版本：
- **YOLOv2 / YOLO9000**：引入 Anchor 机制和批量归一化，提升精度和速度；
- **YOLOv3**：采用多尺度预测和更深的骨干网络（Darknet-53）；
- **YOLOv4**：由 Alexey Bochkovskiy 等人发布，集成多种优化技巧（如 CSPDarknet、PANet）；
- **YOLOv5**：虽非官方原作者开发，但由 Glenn Jocher 使用 **PyTorch 框架实现**，代码易用、训练便捷，成为工业界广泛采用的版本 [来源：PyTorch Book](https://daobook.github.io/pytorch-book/yolo/intro.html)。

YOLO 的主要优势包括：
- **速度快**：可实现实时检测（>30 FPS）；
- **端到端训练**：简化流程，易于部署；
- **全局上下文感知**：因一次性处理整图，不易产生背景误检。

但也存在局限，例如对小目标或密集物体的检测效果相对较弱。
